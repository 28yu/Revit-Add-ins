# RenderKit — Revit モデルを 360°パノラマにしてブラウザで見る

Revit の 3D ビューを **Blender** で写真のようにレンダリングし、
**HTML ファイル1つ**にまとめます。出来た HTML は、ダブルクリックするだけで
どの PC・Mac・スマホのブラウザでも見られます（ネット接続も、アプリのインストールも不要）。

```
Revit ──(FBX 書き出し)──> MakePanorama.bat ──(Blender で自動レンダリング)──> ○○_360.html
```

> これは Revit アドイン（Tools28）とは別の、個人用の道具です。
> 第1段階として 360°パノラマを作ります。次の段階で「歩き回れる 3D」に広げる予定です。

---

## 準備（最初の1回だけ）

1. **Blender をインストールする**（無料）
   - https://www.blender.org/download/ から Windows 版をダウンロードしてインストール
   - バージョンは **4.2 以降**（新しいほど良い）
   - 普通の場所（`C:\Program Files\Blender Foundation\`）に入れれば、自動で見つけます
2. それだけです。Python などを別に入れる必要はありません（Blender に入っています）

---

## 使い方

### 1. Revit で FBX を書き出す

1. Revit で **3D ビュー**を開く
   - **パース（カメラ）ビュー**で書き出すと、そのカメラの位置から撮影します
   - 普通の 3D ビュー（アイソメ）の場合は、モデル全体の中心・床から 1.5m の高さから撮影します
2. 見せたい範囲だけにしたいときは、**切断ボックス**や**非表示**で絞る（書き出しが軽くなります）
3. 「ファイル」→「書き出し」→「FBX」で保存する

### 2. FBX を MakePanorama.bat にドラッグ＆ドロップ

- 黒い画面が開き、進み具合が表示されます
- 終わると、FBX と同じフォルダに **`○○_360.html`** ができ、自動でブラウザが開きます
- 先に仕上がりを素早く確認したいときは **`MakePanorama_Draft.bat`**（下書き品質）を使ってください

### 3. 出来た HTML を見る・渡す

- ドラッグで見回す／マウスホイール・ピンチで拡大縮小／矢印キーでも操作できます
- **HTML ファイル1つだけ**を、メール・チャット・USB などで渡せば相手も見られます
- 同じフォルダにできる `○○_360_1.jpg` はパノラマ画像そのものです（HTML には中身が入っているので、渡す必要はありません）

## 品質と時間の目安

| 品質 | 起動ファイル | 画像サイズ | 目安時間（GPU あり） | 目安時間（CPU のみ） |
|--|--|--|--|--|
| 下書き | `MakePanorama_Draft.bat` | 2048×1024 | 数十秒 | 数分 |
| 標準 | `MakePanorama.bat` | 4096×2048 | 1〜3分 | 20分〜 |
| 高品質 | 下の「細かく指定する」参照 | 8192×4096 | 5〜15分 | 1時間〜 |

時間はモデルの大きさと PC の性能で大きく変わります（CPU のみの下書きは 4コアの PC で約5分を実測。ほかは目安）。
NVIDIA / AMD / Intel Arc の GPU があれば自動で使います。

## 細かく指定する（PowerShell から実行）

`RenderKit` フォルダで PowerShell を開き、次のように実行します。

```powershell
# 高品質で、太陽を真南・高め（夏の昼）にする
powershell -ExecutionPolicy Bypass -File .\MakePanorama.ps1 -Model C:\work\house.fbx -Quality high -SunAzimuth 180 -SunElevation 70

# 撮影位置を2か所指定する（単位はメートル。切り替えボタン付きの HTML になる）
powershell -ExecutionPolicy Bypass -File .\MakePanorama.ps1 -Model C:\work\house.fbx -Eye "2.5,3.0,1.5;8.0,3.0,1.5"

# 少し明るくする（+1 で2倍）
powershell -ExecutionPolicy Bypass -File .\MakePanorama.ps1 -Model C:\work\house.fbx -Exposure 0.5
```

| 指定 | 意味 | 既定値 |
|--|--|--|
| `-Quality` | `draft`（下書き）/ `normal`（標準）/ `high`（高品質） | `normal` |
| `-Eye "X,Y,Z"` | 撮影位置（メートル）。`;` で区切って複数書くとその数だけ作る | 自動 |
| `-EyeHeight` | 自動で決めるときの目の高さ（m） | `1.5` |
| `-SunAzimuth` | 太陽の方位。0=北、90=東、180=南、270=西 | `135`（南東） |
| `-SunElevation` | 太陽の高さ。0=地平線、90=真上 | `40` |
| `-Exposure` | 明るさの補正（自動露出に上乗せ） | `0` |
| `-NoAutoExposure` | 自動露出・自動ホワイトバランスを使わない | — |
| `-Cpu` | GPU を使わない（GPU でエラーが出るとき用） | — |
| `-SaveBlend` | Blender のファイルも保存する（Blender で開いて手直しできる） | — |
| `-Blender` | `blender.exe` の場所（自動で見つからないとき） | 自動 |

※ 「北」はモデルの +Y 方向（Revit の平面図で上）です。

## 自動でやっていること

- **自動露出**: カメラと同じように全体の明るさを測り、暗い室内も明るく見えるように調整します
- **自動ホワイトバランス**: 空の光だけだと全体が青っぽくなるので、色の偏りを半分ほど打ち消します（Blender 4.3 以降）
- **空と太陽**: 実際の大気の計算で作った空と、指定した方向からの太陽光を置きます
- **素材の調整**: Revit のマテリアル名から推測して整えます
  - 名前に「ガラス / glass」→ 透明なガラス（室内に太陽光が入るよう工夫あり）
  - 「鏡 / mirror」→ 鏡、「金属 / steel / アルミ / ステンレス」など → 金属
  - その他 → テカテカしすぎないよう、ほどよいつや消しに
- **見つからないテクスチャ**: 画像ファイルが見つからない模様は外し、色だけで描きます（ピンク色になるのを防ぐ）

## うまくいかないとき

| 症状 | 対処 |
|--|--|
| 「Blender が見つかりませんでした」 | Blender をインストールする。別の場所なら `-Blender "D:\...\blender.exe"` で指定 |
| 「大きさが建物として不自然です」 | Revit の書き出し時の単位設定を確認する |
| 撮影位置が壁の中・外になる | パースビューで書き出すか、`-Eye` で位置を指定する |
| 暗すぎる／明るすぎる | `-Exposure 1`（明るく）／`-Exposure -1`（暗く） |
| GPU のエラーで止まる | `-Cpu` を付けて実行する |
| 模様（木目など）が出ない | Revit の FBX では模様の画像が引き継がれないことがあるため。今後の Tools28 の書き出し機能で対応予定 |

## ファイル構成

| ファイル | 役割 |
|--|--|
| `MakePanorama.bat` | FBX をドラッグ＆ドロップする起動ファイル（標準品質） |
| `MakePanorama_Draft.bat` | 同上（下書き品質） |
| `MakePanorama.ps1` | Blender を探して実行する本体 |
| `blender/render_panorama.py` | Blender の中で動くスクリプト（読み込み・素材調整・空・撮影） |
| `make_viewer.py` | パノラマ画像を HTML に埋め込む。単体でも使える: `python make_viewer.py 出力.html 画像.jpg` |
| `viewer/panorama_viewer.html` | 360°ビューアのひな形（外部ライブラリなし・WebGL のみ） |
