# 切断ボックス合わせ

3Dビューの切断ボックス（セクションボックス）の範囲を、別の3Dビューにそのまま写します。

![Before / After：同じ範囲で切り取られた2つの3Dビュー](./images/SectionBoxCopy/00-result.png)

---

## 使い方

操作は Revit の「タイプ プロパティを一致」（MA）と同じ感覚です。

### 1. コピー元で押す

コピー元の3Dビューを開き、「**28 Tools**」タブ →「**3Dビュー**」パネル →「**切断ボックス合わせ**」をクリック。切断ボックスを覚え、**カーソルの横に印**が出ます。

![「切断ボックス合わせ」をクリックすると、カーソルの横に印が出る](./images/SectionBoxCopy/01-copy.png)

### 2. 合わせたいビューで押す

印が出ている間に、合わせたい3Dビューを開いて「**切断ボックス合わせ**」をクリックすると、すぐに貼られます。続けてほかのビューにも貼れます。

![合わせたいビューで「切断ボックス合わせ」をクリック](./images/SectionBoxCopy/02-paste.png)

| こんなとき | 操作 |
|---|---|
| 何枚もの3Dビューにまとめて貼る | プロジェクトブラウザで3Dビューを複数選んでからボタンを押す |
| 視点と切断ボックスを一度に貼る | 「視点合わせ」と「切断ボックス合わせ」を両方押して印を2つ出してから、合わせたいビューでどちらかを押す |
| コピーを取りやめる | **Esc**（印が消えます） |

---

## 注意

- 切断ボックスのオン／オフもコピー元に合わせます（オフをコピーすると、貼り付け先もオフ）
- コピー内容は Revit を閉じると消えます
- 範囲外の要素は見えなくなります。見えないときは切断ボックスの範囲を確認してください
