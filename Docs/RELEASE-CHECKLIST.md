## 使い方

- チェック欄は `[ ]` → 確認OKなら `[x]`、NGなら `[!]` にして下に不具合をメモする
- **A表（ビルド）と B表（共通スモーク）は全6バージョンで実施**する
- **C表（バージョン依存）は該当バージョンのみ**実施する
- **D表（機能別）は代表1バージョン（既定: Revit 2022）で実施**すればよい。
  ただし「要全数」と書いた行だけは全バージョンで実施する
- 所要目安: A+B = 1バージョンあたり約10分（×6 = 約1時間）／ D = 約60分
