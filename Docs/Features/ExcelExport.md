# EXCELエクスポート 使い方ガイド

Revit要素のパラメータ値をExcelファイル（.xlsx）に書き出す機能です。パラメータの一括確認・納品用の数量書き出しに活用できます。

---

## できること

- Revit要素の**パラメータ値をExcelに書き出し**ます
- エクスポート範囲を**プロジェクト全体 / アクティブビュー / 選択要素**から選べます
- インスタンスパラメータ・タイプパラメータの両方に対応しています
- 通り芯・レベル・シートなどの注釈カテゴリにも対応しています
- 前回の設定（カテゴリ・パラメータ選択）を自動復元します

---

## 実行手順

### ▶ ステップ1: コマンドの起動

リボン「**28 Tools**」タブ →「**データ**」パネル →「**EXCELエクスポート**」ボタンをクリックします。

### ▶ ステップ2: エクスポート範囲の選択

スコープ選択ダイアログが表示されます。

| 選択肢 | 対象 |
|---|---|
| **プロジェクト全体** | プロジェクト内のすべての要素 |
| **アクティブビュー** | 現在表示中のビューに存在する要素のみ |
| **選択要素** | 事前に選択しておいた要素のみ |

### ▶ ステップ3: カテゴリとパラメータの選択

設定ダイアログが開きます。

| 項目 | 内容 |
|---|---|
| **カテゴリ一覧** | エクスポートしたいカテゴリにチェックを入れる（検索ボックスで絞り込み可） |
| **パラメータ一覧** | 各カテゴリでエクスポートするパラメータを選択 |
| **カテゴリ別シート** | カテゴリごとに別シートへ出力（デフォルト） |
| **シート統合** | 全カテゴリを1枚のシート（「データ」／英語版は「Data」）にまとめて出力 |
| **パラメータグループも書き出す** | オンにすると、見出しの上に1行追加して各パラメータのグループ（「寸法」「識別情報」など）を書き出す（デフォルトはオフ） |

> 💡 前回の設定は自動的に復元されます。毎回同じ設定で出力する場合は2回目以降の操作が省略できます。

### ▶ ステップ4: ファイルを保存

「**エクスポート**」ボタンをクリックし、保存先とファイル名を指定します。

---

## 出力されるExcelの形式

| 項目 | 内容 |
|---|---|
| **シート構成** | カテゴリ別シート（デフォルト）、またはシート統合モードで1シート |
| **ヘッダー行** | 要素ID \| カテゴリ \| パラメータ名... |
| **パラメータグループ行** | 「パラメータグループも書き出す」をオンにした場合のみ、1行目にグループ名、2行目に見出しを出力（同じグループが隣り合う列はセルを結合） |
| **パラメータ接頭辞** | `I-`（インスタンスパラメータ）/ `T-`（タイプパラメータ） |
| **ヘッダー色** | 緑（RGB: 155, 187, 89）＋白文字 |
| **フォント** | ＭＳ 明朝 |
| **数値** | 数値型で保存（文字列ではない） |
| **オートフィルタ** | 自動設定済み |

> 💡 ヘッダーの「要素ID」「カテゴリ」やシート名、編集可否マーカー（`(*変更不可)` 等）は、**書き出し時のアドイン言語**で出力されます。読み込み側は3言語すべての表記を認識するため、**別の言語で書き出した Excel もそのまま取り込めます**（日本語固定だった旧バージョンの Excel も読めます）。

> 💡 パラメータグループ行は**参考表示のみ**です。Excel でグループ名を書き換えて読み込んでも、Revit のパラメータグループは変わりません。グループ行がある Excel もない Excel も、EXCELインポートと出力設定の「Excel」読込でそのまま読み込めます。グループ名は **Revit 本体の表示言語**で出力されます（日本語版 Revit なら「寸法」、英語版なら「Dimensions」）。

## トラブルシューティング

### カテゴリが一覧に表示されない

- アクティブビューやスコープに要素が存在しない場合、そのカテゴリは表示されません
- **プロジェクト全体**スコープで実行するとより多くのカテゴリが表示されます

### 通り芯・レベルなどの注釈要素が表示されない

- アクティブビューに通り芯・レベルが表示されている状態でエクスポートすると一覧に表示されます
- プロジェクト全体スコープでも対応しています

### 大きなモデルでエクスポートが終わらない

- エクスポート中は進み具合の画面（カテゴリ・要素数・経過時間）が表示され、**「キャンセル」で途中で止められます**（Excel ファイルは作成されません）
- 読み取りに時間のかかるパラメータがあると、画面に「時間のかかっているパラメータ」が表示されます。キャンセル時のメッセージにも上位が表示されるので、**そのパラメータを出力から外して再実行**してください
  - 設備（MEP）系の計算値（流量・圧力損失など）は、読み取るたびに Revit が計算し直すため特に時間がかかることがあります
- 処理時間の記録は `C:\temp\Tools28_debug.txt` に `[ExcelExport]` として残ります。不具合報告の際に添えてください
