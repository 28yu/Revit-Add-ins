# EXCELエクスポート 使い方ガイド

Revit要素のパラメータ値をExcelファイル（.xlsx）に書き出す機能です。パラメータの一括確認・納品用の数量書き出しに活用できます。

---

## できること

- Revit要素の**パラメータ値をExcelに書き出し**ます
- エクスポート範囲を**プロジェクト全体 / アクティブビュー / 選択要素**から選べます
- インスタンスパラメータ・タイプパラメータの両方に対応しています
- 通り芯・レベル・シートなどの注釈カテゴリにも対応しています
- **カテゴリを選ばずにパラメータ名・パラメータグループで検索**し、複数カテゴリの同じパラメータをまとめて書き出せます
- 出力設定（カテゴリ・パラメータと並び順）を**設定ファイル(.json)に保存／読込**できるほか、**書き出し済みの Excel から読み込む**こともできます
- 大きなモデルでも**進み具合を表示し、途中でキャンセル**できます
- 書き出した Excel は見出し行が固定され、**値を変更できない列はグレー表示＋見出しに目印**が付きます

---

## 実行手順

### ▶ ステップ1: コマンドの起動

リボン「**28 Tools**」タブ →「**Excel連携**」パネル →「**Excel エクスポート**」ボタンをクリックします。

### ▶ ステップ2: エクスポート範囲の選択

「書出し範囲の選択」ダイアログが表示されます。書き出す範囲のボタンをクリックします。

| 選択肢 | 対象 |
|---|---|
| **プロジェクト全体の要素** | プロジェクト内のすべての要素 |
| **現在のビューにある要素** | 現在表示中のビューに存在する要素のみ |
| **現在選択されている要素** | 事前に選択しておいた要素のみ（要素を選択していないときは押せません） |

### ▶ ステップ3: カテゴリとパラメータの選択

設定ダイアログが開きます。左から「**カテゴリを選択**」「**パラメータ**」「**出力**」の3つの欄が並びます。

| 項目 | 内容 |
|---|---|
| **カテゴリを選択** | エクスポートしたいカテゴリにチェックを入れる（検索ボックスで絞り込み可）。「**全選択**」「**選択解除**」は、検索で絞り込んで表示中のカテゴリだけが対象 |
| **パラメータ** | チェックしたカテゴリのパラメータがカテゴリ別の見出しの下に並ぶ。**見出しをクリックすると折りたたみ／展開**できる。「全選択」「選択解除」は表示中のパラメータだけが対象 |
| **グループ** | パラメータ一覧をパラメータグループ（「寸法」「識別情報」など）で絞り込む。各パラメータ名の右にも `[グループ名]` を薄字で表示 |
| **＞ / ＜** | パラメータ欄でチェックしたものを出力欄へ追加（＞）／出力欄で選択したものを外す（＜） |
| **出力** | 書き出すパラメータの一覧。この並び順が Excel の列順になる。カテゴリ別の見出しは折りたたみ可能。検索ボックスで絞り込みも可 |
| **▲ / ▼** | 出力欄で選択したパラメータを上下に移動。**Ctrl / Shift で複数選択**してまとめて動かせる（並び替えはカテゴリの中で行われる） |
| **クリア** | 出力欄のパラメータをすべて外す（確認メッセージあり） |
| **出力Excelをカテゴリ毎にシートに分ける** | オン（デフォルト）でカテゴリごとに別シートへ出力。オフにすると全カテゴリを1枚のシート（「データ」／英語版は「Data」）にまとめて出力 |
| **パラメータグループも書き出す** | オンにすると、見出しの上に1行追加して各パラメータのグループ（「寸法」「識別情報」など）を書き出す（デフォルトはオフ） |

パラメータ名の頭の `I-` はインスタンス（要素）パラメータ、`T-` はタイプパラメータを表します（ダイアログ下部にも凡例を表示）。
同じカテゴリに同じ名前のパラメータが複数ある場合は、`I-用途【組み込み】` `I-用途【共有】` のように種別（組み込み／共有／プロジェクト）を付けて区別します。

#### 特定のパラメータ名・パラメータグループで絞って書き出す

複数カテゴリにまたがって、同じ名前やグループのパラメータだけをまとめて書き出せます。
**カテゴリを選ばなくても使えます。**

1. カテゴリには**チェックを付けないまま**にする
2. パラメータ欄の検索ボックスに**パラメータ名**を入力する（例:「マーク」）
   → そのパラメータを持つ**すべてのカテゴリ**が表示されます
3. 必要なら「**グループ**」でさらに絞り込む（例:「識別情報」）。グループだけで絞り込むこともできます
4. パラメータ欄の「**全選択**」→「**＞**」で出力欄へまとめて追加
5. 「**エクスポート実行**」。出力欄に入れたパラメータのカテゴリが自動で書き出し対象になります

- カテゴリに1つでもチェックを付けた場合は、従来どおりチェックしたカテゴリの中だけで検索します。
- 初回の検索（またはグループ欄を開いたとき）は全カテゴリのパラメータを読み込みます。パラメータ欄の下に「読み込み中… 12/80 カテゴリ」のように進み具合が表示され、その間も画面は操作できます（カテゴリ選択・出力欄への追加・エクスポート実行は読み込み完了まで押せません）。2回目以降は読み込み済みのため速くなります。
- 検索は**入力が止まってから約0.4秒後**に実行されます（日本語入力の変換中に1文字ごとに処理が走らないようにするため）。
- 「全選択」は絞り込み後に表示されているパラメータだけが対象です。

#### 出力設定の保存・読込

毎回同じパラメータを書き出す場合は、出力欄の上のボタンで設定を使い回せます。

| ボタン | 内容 |
|---|---|
| **読込** | 保存した設定ファイル(.json)から設定を読み込む |
| **Excel読込** | **書き出し済みの Excel** から出力設定（カテゴリ・パラメータ・列の並び・グループ行の有無）を読み込む。前回書き出したファイルを選ぶだけで同じ設定に戻せる |
| **保存** | 現在の設定をファイル(.json)に保存する |

- 「Excel読込」は、Excel の列を入れ替えていても読み込めます。このアドインで書き出していない Excel を選ぶと「出力設定を読み取れませんでした」と表示されます。
- 今回の書出し範囲に存在しないパラメータは復元されません（「○件中○件を復元しました」と表示）。
- 設定はダイアログを閉じると保持されません。次回も同じ内容で書き出したい場合は「保存」しておくか、「Excel読込」を使ってください。

### ▶ ステップ4: ファイルを保存

「**エクスポート実行**」ボタンをクリックし、保存先とファイル名を指定します。
保存先の選択をキャンセルした場合は設定ダイアログに戻ります（選択内容はそのまま残ります）。

書き出しが始まると進み具合の画面（カテゴリ・要素数・経過時間）が表示され、「**キャンセル**」で途中で止められます。処理中は Revit を操作できません。
完了すると、書き出した Excel ファイルが自動で開きます。

## 出力されるExcelの形式

| 項目 | 内容 |
|---|---|
| **シート構成** | カテゴリ別シート（デフォルト）、またはシート統合モードで1シート |
| **ヘッダー行** | 要素ID \| カテゴリ \| パラメータ名... |
| **パラメータグループ行** | 「パラメータグループも書き出す」をオンにした場合のみ、1行目にグループ名、2行目に見出しを出力（同じグループが隣り合う列はセルを結合） |
| **パラメータ接頭辞** | `I-`（インスタンスパラメータ）/ `T-`（タイプパラメータ） |
| **ヘッダー色** | 緑（RGB: 155, 187, 89）＋白文字 |
| **見出しの固定** | 見出し行（グループ行があればそれも含む）を固定。下へスクロールしても見出しが常に表示される |
| **変更できない列** | 見出しをグレー＋斜体にし、名前の後ろに目印を付ける。データの文字もグレーで表示（下表） |
| **フォント** | ＭＳ 明朝 |
| **数値** | 数値として読める値は数値型で保存（文字列ではない）。長さ・面積などは Revit 上の表示と同じ単位（mm・㎡ 等）の値 |
| **要素参照の値** | レベル・材料などの参照は**要素名**で出力（例: 部屋の「上部レベル」→ `2FL`） |
| **オートフィルタ** | 自動設定済み |
| **隠しシート** | 各列がどのパラメータかを記録した `Tools28_ParamIds`（インポートで使用。削除・変更しない） |

#### 見出しの目印（値を直接入力できない列）

| 目印 | 意味 |
|---|---|
| `(*変更不可)` | 読み取り専用。長さ・面積などの計算値で、インポートしても変更できない |
| `(*要素参照/名称必須)` | レベル・材料などの参照。**モデルに実在する要素名**を入力すれば変更できる（自由な文字は入れられない） |
| `(*画像参照/文字不可)` | 「イメージ」などの画像の参照。自由な文字は入れられない（モデルに読み込み済みの画像の名前を入れた場合のみ設定できる） |

- 「タイプ」列には目印は付きません。**既存のタイプ名**を入力してインポートすると、要素のタイプを変更できます。
- 目印は見出しの表示用です。インポート時は自動で取り除いて照合するので、見出しを書き換える必要はありません。

> 💡 ヘッダーの「要素ID」「カテゴリ」やシート名、編集可否マーカー（`(*変更不可)` 等）は、**書き出し時のアドイン言語**で出力されます。読み込み側は3言語すべての表記を認識するため、**別の言語で書き出した Excel もそのまま取り込めます**（日本語固定だった旧バージョンの Excel も読めます）。

> 💡 パラメータグループ行は**参考表示のみ**です。Excel でグループ名を書き換えて読み込んでも、Revit のパラメータグループは変わりません。グループ行がある Excel もない Excel も、EXCELインポートと出力設定の「Excel読込」でそのまま読み込めます。グループ名は **Revit 本体の表示言語**で出力されます（日本語版 Revit なら「寸法」、英語版なら「Dimensions」）。

## トラブルシューティング

### カテゴリが一覧に表示されない

- アクティブビューやスコープに要素が存在しない場合、そのカテゴリは表示されません
- **プロジェクト全体**スコープで実行するとより多くのカテゴリが表示されます

### 通り芯・レベルなどの注釈要素が表示されない

- アクティブビューに通り芯・レベルが表示されている状態でエクスポートすると一覧に表示されます
- プロジェクト全体スコープでも対応しています

### 大きなモデルでエクスポートが終わらない

- エクスポート中は進み具合の画面（カテゴリ・要素数・経過時間）が表示され、**「キャンセル」で途中で止められます**（Excel ファイルは作成されません）
- 読み取りに時間のかかるパラメータがあると、画面に「時間のかかっているパラメータ」が表示されます。キャンセル時のメッセージにも上位が表示されるので、**そのパラメータを出力から外して再実行**してください
  - 設備（MEP）系の計算値（流量・圧力損失など）は、読み取るたびに Revit が計算し直すため特に時間がかかることがあります
- 処理時間の記録は `C:\temp\Tools28_debug.txt` に `[ExcelExport]` として残ります。不具合報告の際に添えてください
