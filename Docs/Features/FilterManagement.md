# フィルタ整理（使用ビュー確認・名前変更・削除）

プロジェクト内の**すべてのフィルタ**（表示/グラフィックスの上書きで使うフィルタ）を一覧表示し、各フィルタが**どのビューで使われているか（または未使用か）**を確認しながら、**名前の変更**や**不要なフィルタの削除**を行う機能です。

大規模なモデルほど図面（ビュー）の数が増え、それに伴ってフィルタも増えていきます。過去のプロジェクトからの流用や試行錯誤で作ったフィルタが放置され、どれが実際に使われているのか分からなくなりがちです。本機能はそれらを一画面で整理できます。

## 対象フィルタ

| 種別 | 内容 |
|------|------|
| ルール | ルールベースフィルタ（`ParameterFilterElement`）。カテゴリと条件で対象要素を絞り込む一般的なフィルタ。 |
| 選択 | 選択フィルタ（`SelectionFilterElement`）。手動で選んだ要素の集合をフィルタとして扱うもの。 |

## 使い方

1. リボン **28 Tools ＞ シート・ビュー ＞ フィルタ整理** をクリックします。
2. ダイアログにプロジェクト内の全フィルタが一覧表示されます。各列の意味は次のとおりです。

   | 列 | 内容 |
   |----|------|
   | 選択 | 削除対象にするチェックボックス |
   | フィルタ名 | フィルタの名前（**ダブルクリックで変更可能**） |
   | 種別 | ルール／選択 |
   | 対象カテゴリ | ルールベースフィルタが対象とするカテゴリ |
   | 使用数 | そのフィルタを使用しているビュー数 |
   | 使用状況（ビュー） | 使用しているビュー名の一覧。どのビューでも使われていない場合は赤字で **未使用** と表示 |

   - ビューテンプレートで使用されている場合は、ビュー名の前に **[テンプレート]** と表示されます。
3. 上部の **検索** 欄にフィルタ名を入力すると、名前で絞り込めます。**「未使用のみ」** チェックや **種別**（すべて／ルール／選択）でも絞り込めます。

### 名前の変更

- 一覧の **フィルタ名** をダブルクリックすると編集状態になります。新しい名前を入力して Enter（またはセルの外をクリック）すると、その場で名前が変更されます。
- 変更したフィルタ名はオレンジ色で強調表示されます。
- 既に同じ名前のフィルタが存在する場合や、空の名前にした場合は変更できず、元の名前に戻ります。

### 削除

1. 削除したいフィルタの **「選択」** チェックを入れます。
   - **「未使用を全選択」** ボタンで、どのビューでも使われていないフィルタを一括選択できます。
   - **「全選択」／「選択解除」** ボタンは、検索・絞り込みで**表示中の行だけ**を対象にします。
2. **「選択したフィルタを削除」** を押し、確認ダイアログで **はい** を選ぶと削除が実行されます。
   - 使用中のフィルタが含まれている場合は、確認ダイアログでその件数を警告します。使用中のフィルタを削除すると、そのビューの表示/グラフィックスの上書きから取り除かれます。

## 注意事項

- **削除は元に戻せません**（Undo は効きません）。使用状況をよく確認してから実行してください。
- 使用状況は、通常ビューとビューテンプレートの両方を走査して判定しています。あるビューがテンプレートでフィルタを制御している場合、そのフィルタは **テンプレート側で使用中** として表示されます。
- フィルタの追加・削除・名前変更をワークシェアリング環境で行う場合は、対象要素の所有権に注意してください。

## 関連機能

- **パラメータ整理** — 未使用パラメータの洗い出しと削除。フィルタと同様に、長年運用したモデルの不要データを整理できます。
