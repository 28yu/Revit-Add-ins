# 自動バックアップ（定期ローカル保存）

作業中の Revit モデルを、一定間隔（既定 15 分）で自動的にローカルフォルダへバックアップする機能です。

## 特長

- **作業を中断しない** — Revit が空いた瞬間（アイドル状態）を狙って保存するため、操作中に割り込みません。
  - ※ Revit API はシングルスレッドのため、保存処理そのものが走る一瞬だけは動作が止まります。大規模モデルほど保存時間は長くなりますが、アイドル時に限定することで体感の停止を最小化しています。
- **最新状態を保存** — 未保存の変更もいったんモデルに保存してから、その最新ファイルをバックアップ先へコピーします（設定で無効化も可能）。
- **世代管理** — モデルごとに指定した世代数だけ残し、古いバックアップは自動削除します。

## 使い方

1. リボン **28 Tools → 設定 → 自動バックアップ** をクリックします。
2. 設定ダイアログで以下を設定します。
   - **自動バックアップを有効にする**: チェックすると定期バックアップが開始します。
   - **バックアップ間隔**: 何分ごとに保存するか（1 以上の整数）。
   - **バックアップ先**:
     - *モデルと同じ場所*: モデルフォルダ直下の `Tools28_Backups` フォルダに保存します。
     - *指定フォルダ*: 任意のフォルダを指定します（`...` ボタンで参照）。
   - **保存する世代数**: 保持するバックアップの数（超過分は古い順に削除）。
   - **未保存の変更も保存してからバックアップする**: オンで最新状態、オフでディスク上の最終保存状態をコピー。
3. **今すぐバックアップ** ボタンで、その場で 1 回バックアップを実行できます。
4. **OK** で設定を保存します。設定は次回起動時にも引き継がれます。

## バックアップファイルの命名

```
{モデル名}_backup_{yyyyMMdd_HHmmss}.rvt
例: Project1_backup_20260730_143015.rvt
```

## 注意事項

- モデルが一度も保存されていない（ファイルパスが無い）場合、リンクモデルの場合はバックアップ対象外です。
- ワークシェアリング（共同作業）モデルではローカルファイルの状態がコピーされます。
- 設定は `%AppData%\Tools28\AutoBackupSettings.json` に保存されます。
