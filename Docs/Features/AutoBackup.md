# 自動バックアップ（定期ローカル保存）

作業中の Revit モデルを、一定間隔（既定 15 分）で自動的にローカルフォルダへバックアップする機能です。

## 特長

- **作業を中断しない** — Revit が空いた瞬間（アイドル状態）を狙って保存するため、操作中に割り込みません。
  - ※ Revit API はシングルスレッドのため、保存処理そのものが走る一瞬だけは動作が止まります。大規模モデルほど保存時間は長くなりますが、アイドル時に限定することで体感の停止を最小化しています。
- **最新状態を保存** — 未保存の変更もいったんモデルに保存してから、その最新ファイルをバックアップ先へコピーします（設定で無効化も可能）。
- **世代管理** — モデルごとに指定した世代数だけ残し、古いバックアップは自動削除します。

## 使い方

1. リボン **28 Tools → 設定 → 自動バックアップ** をクリックします。
2. 設定ダイアログで以下を設定します。
   - **自動バックアップを有効にする**: チェックすると定期バックアップが開始します。
   - **バックアップ間隔**: 何分ごとに保存するか（1 以上の整数）。
   - **バックアップ先**:
     - *モデルと同じ場所*: モデルフォルダ直下の `Tools28_Backups` フォルダに保存します。
     - *指定フォルダ*: 任意のフォルダを指定します（`...` ボタンで参照）。
   - **保存する世代数**: 保持するバックアップの数（超過分は古い順に削除）。
   - **未保存の変更も保存してからバックアップする**: オンで最新状態、オフでディスク上の最終保存状態をコピー。
3. **今すぐバックアップ** ボタンで、その場で 1 回バックアップを実行できます。
4. **OK** で設定を保存します。設定は次回起動時にも引き継がれます。

## バックアップファイルの命名

```
{モデル名}_backup_{yyyyMMdd_HHmmss}.rvt
例: Project1_backup_20260730_143015.rvt
```

## ワークシェア／クラウドモデルへの対応

チェックボックス **「ワークシェアモデルは中央モデルに自動同期する（クラウド対応）」** をオンにすると、
ワークシェアリング（共同作業）モデルではファイルコピーの代わりに **Synchronize with Central（中央モデルへの同期）** を実行します。

- **クラウド中央モデル（BIM 360 / ACC）** は、ディスク上に単体でコピーできる `.rvt` を持たないため、ファイルコピー方式ではバックアップできません。この設定をオンにすると定期的に中央へ同期し、**ACC / BIM 360 のバージョン履歴がバックアップ**になります。
- 同期時は継続作業を妨げないよう、要素の所有権（借用）は返却しません。
- 同期は通常のローカル保存より重く、他メンバーと競合しうるため、**既定はオフ（オプトイン）** です。
- この設定がオフのままクラウドモデルを開いている場合、バックアップは実行されず、その旨のステータスが表示されます。

#### 作業への割り込みを抑える工夫
- **モデルを開いた直後は同期しません**。開いた時点で間隔カウントがリセットされ、1間隔ぶん経過してから初回同期が走ります（各バックアップ完了時にもリセット）。
- 同期中に確認ダイアログが出ても**自動的に継続処理**し、クリック待ちで止まりません。
- 中央が**他メンバーの同期でロック中の場合は待たずにスキップ**し、次回に委ねます（待機ダイアログで固まりません）。

> ⚠️ **重要（Revit の仕様）**: Synchronize with Central は中央モデルをロックする排他処理のため、**同期の実行中（進捗バーが出ている間）はモデルを編集できません**。これは Revit 本体の手動同期と同じで、API でバックグラウンド化することはできません。上記の工夫は「作業中に割り込まれない」ようにするもので、同期の一瞬の停止自体は避けられません。同期時間を短くするには間隔を適切に設定し、モデルを軽く保つことが有効です。

### 過去バージョンへ戻したい（復元）とき
クラウド中央モデルを過去の状態に戻すには、**ACC / BIM 360 Docs のバージョン履歴 → 復元（Restore）** を使うのが公式かつ確実な方法です（Web 上で操作、アドイン不要）。

## 注意事項

- モデルが一度も保存されていない（ファイルパスが無い）場合、リンクモデルの場合はバックアップ対象外です。
- ローカル（非クラウド）のワークシェア中央モデルは、自動同期がオフでもローカルファイルのコピーでバックアップされます。
- 設定は `%AppData%\Tools28\AutoBackupSettings.json` に保存されます。
