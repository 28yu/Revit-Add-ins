# トリミング領域 コピー＆ペースト

ビューのトリミング領域（表示範囲）を、別のビューにそのまま写します。各階の平面図の範囲をそろえるときに使います。

![Before / After：表示範囲がそろった2つの平面図](./images/CropBoxCopy/00-result.png)

---

## 使い方

### 1. トリミング領域をコピー

コピー元のビューを開き、「**28 Tools**」タブ →「**シート・ビュー**」パネル →「**領域コピー**」をクリック。

![「領域コピー」をクリック](./images/CropBoxCopy/01-copy.png)

### 2. トリミング領域をペースト

貼り付け先のビューを開き、「**領域ペースト**」をクリック。

![「領域ペースト」をクリック](./images/CropBoxCopy/02-paste.png)

> 💡 プロジェクトブラウザでビューを**複数選択**してからペーストすると、まとめて適用できます。

---

## 注意

- 使えるビュー：平面図・天井伏図・断面図・立面図・詳細図・3Dビュー
- トリミングのオン／オフと枠の表示もコピー元に合わせます
- スケールや向きが違うビュー同士では、範囲がずれることがあります
- コピー内容は Revit を閉じると消えます
