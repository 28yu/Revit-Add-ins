# パラメータ値の移動 使い方ガイド

**同じ名前でパラメータグループが違う**文字パラメータの間で、値を要素ごとに移動する機能です。

**例**: GUID 違いの共有パラメータ「☆財産区分」が「モデル プロパティ」と「セット」の2つに分かれていて、値がバラバラに入っている → すべて「セット」側にまとめる。

Excel で列を移す作業を、Revit 上で直接まとめて行えます（書き出し・読み込みは不要）。

---

## 実行手順

### ▶ ステップ1: 起動して読み込む

リボン「**28 Tools**」タブ →「**パラメータ**」パネル →「**値の移動**」をクリックします。

範囲（プロジェクト全体 / アクティブビュー / 選択要素）と「タイプパラメータも対象」を選び、「**パラメータを読み込む**」をクリックします。
同じ名前で2つ以上のグループにあるパラメータが集計されます（大容量モデルでは時間がかかります。進み具合が表示され、「中止」で止められます）。

### ▶ ステップ2: 移動元・移動先を選んで確認

| 項目 | 内容 |
|---|---|
| **移動元のグループ** | 値を取り出す側（例: モデル プロパティ） |
| **移動先のグループ** | 値を入れる側（例: セット） |
| **移動先にすでに違う値がある要素** | 「移動先の値を残す（その要素は移動しない）」または「移動元の値で上書きする」 |

一覧には、移動元・移動先の両方のグループにあるパラメータ名だけが表示されます。移動するパラメータにチェックを付けて「**確認（件数を数える）**」をクリックすると、パラメータごとに次の件数が表示されます（この時点ではまだ変更しません）。

| 列 | 意味 |
|---|---|
| **移動する** | 実際に移動する要素の数 |
| **移動先なし** | 要素（ファミリ）が移動先のパラメータを持っていないため移動できない数。移動元の値はそのまま残ります |
| **移動先に値あり** | 移動先にすでに違う値があった数（「残す」なら移動しない／「上書き」なら上書きする） |
| **値の食い違い** | 同じグループに同名パラメータが複数あり、違う値が入っていて決められない数（移動しません） |

### ▶ ステップ3: 移動を実行

「**移動を実行**」→ 確認画面で「はい」。移動先へ値を書き込み、**移動元は空欄**になります。

- 実行中は進み具合が表示され、「中止」で止めると**それまでの変更はすべて元に戻ります**
- 実行後は Revit の「元に戻す」（Ctrl+Z）1回で、移動全体を取り消せます
- 条件（グループ・チェック・上書きの選択）を変えたら、もう一度「確認」してから実行してください

---

## 値を失わないためのルール

- 移動先のパラメータを持たない要素は**移動しません**（移動元の値を消しません）
- 移動元に違う値が複数ある要素は**移動しません**
- 移動先にすでに値がある要素は、「残す」を選べば**変更しません**
