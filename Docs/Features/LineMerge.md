# 直線まとめ

同じ直線上に並んだ**詳細線・モデル線**を、1本の線にまとめます。CAD を分解したときにバラバラになった線の整理に使えます。

![バラバラの線が1本になる](./images/LineMerge/00-result.png)

## 使い方

### 1. 線を選ぶ

まとめたい線を範囲選択します（何も選ばずにボタンを押した場合は、押したあとに選びます）。

### 2. 「直線まとめ」をクリック

**28 Tools ＞ 注釈・詳細 ＞ 直線まとめ** をクリックします。同じ直線上にある線が1本になり、まとめた本数が表示されます。

![「直線まとめ」をクリック](./images/LineMerge/01-button.png)

- 同じ直線上にあれば、**離れている線もつなぎます**（すき間は埋まります）
- 角度のある線、平行でも横にずれている線はつなぎません
- いちばん長い線を伸ばして残すため、その線の線種になり、その線に付いた寸法も残ります
- 円弧・ピン留めした線・グループ内の線は対象外です
- 読み込んだ CAD の線は、CAD を選んで「分解」してから実行してください
- 元に戻すときは Ctrl+Z を押します
