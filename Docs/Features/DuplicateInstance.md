# 重複要素整理（同じ場所に同一のインスタンス）

Revit の警告「**同じ場所に同一のインスタンスがあります**」に出てくる要素を一覧にし、重なっている要素の**パラメータを見比べて、不要な方を削除**する機能です。

![重なった要素のパラメータを見比べて削除](./images/DuplicateInstance/00-result.png)

## 使い方

### 1. リボンから実行

**28 Tools ＞ モデル ＞ 重複要素整理** をクリックします。

![「重複要素整理」をクリック](./images/DuplicateInstance/01-ribbon.png)

### 2. 見比べる

上の一覧は1要素1行です。同じ場所で重なっている要素は同じ「**組**」の番号になります。行を選ぶと、下の表にその組の**全パラメータ**が並び、**違う値は黄色**になります。

![行を選ぶと下の表で見比べられる](./images/DuplicateInstance/02-compare.png)

- 列見出しのクリックで並べ替え、上の「検索」「カテゴリ」で絞り込み
- 「違う値のみ表示」で、差のあるパラメータだけに絞れます
- 「**画面で確認**」（または行のダブルクリック）で Revit 上で選択・ズーム。**Esc** で一覧に戻ります

### 3. 削除する

消す方の「削除」にチェックを付けて「**チェックした要素を削除**」。「**値が少ないほうを選択**」を押すと、組ごとに値の入っているパラメータが一番多い要素を残して、ほかに自動でチェックが付きます（同数なら先に作られた方＝要素IDが小さい方を残す）。

![チェックして削除](./images/DuplicateInstance/03-delete.png)

> 削除は Revit の「元に戻す」で取り消せます。組の全要素にチェックが付いているときは、削除前に注意が出ます。
