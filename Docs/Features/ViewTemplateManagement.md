# テンプレート整理（使用ビュー確認・名前変更・削除）

プロジェクト内の**すべてのビューテンプレート**を一覧表示し、各テンプレートが**どのビューに適用されているか（または未使用か）**を確認しながら、**名前の変更**や**不要なテンプレートの削除**を行う機能です。

大規模なモデルほどビューの数が増え、それに合わせてビューテンプレートも増えていきます。過去プロジェクトからの流用や試行錯誤で作ったテンプレートが放置され、どれが実際に使われているのか分からなくなりがちです。本機能はそれらを一画面で整理できます（フィルタ整理のテンプレート版です）。

## 使い方

1. リボン **28 Tools ＞ シート・ビュー ＞ テンプレート整理** をクリックします。
2. ダイアログにプロジェクト内の全ビューテンプレートが一覧表示されます。各列の意味は次のとおりです。

   | 列 | 内容 |
   |----|------|
   | 選択 | 削除対象にするチェックボックス |
   | テンプレート名 | テンプレートの名前（**ダブルクリックで変更可能**） |
   | 種別 | テンプレートのビュー種別（平面図／断面図／3D など） |
   | 使用数 | そのテンプレートを適用しているビュー数 |
   | 使用状況（ビュー） | 適用しているビュー名の一覧。どのビューにも適用されていない場合は赤字で **未使用** と表示 |

3. 上部の **検索** 欄にテンプレート名を入力すると、名前で絞り込めます。**「未使用のみ」** チェックで未使用テンプレートだけに絞り込めます。

### 名前の変更

- 一覧の **テンプレート名** をダブルクリックすると編集状態になります。新しい名前を入力して Enter（またはセルの外をクリック）すると、その場で名前が変更されます。
- 変更したテンプレート名はオレンジ色で強調表示されます。
- 既に同じ名前のテンプレートが存在する場合や、空の名前にした場合は変更できず、元の名前に戻ります。

### 削除

1. 削除したいテンプレートの **「選択」** チェックを入れます。
   - **「未使用を全選択」** ボタンで、どのビューにも適用されていないテンプレートを一括選択できます。
   - **「全選択」／「選択解除」** ボタンは、検索・絞り込みで**表示中の行だけ**を対象にします。
2. **「選択したテンプレートを削除」** を押し、確認ダイアログで **はい** を選ぶと削除が実行されます。
   - 使用中のテンプレートが含まれている場合は、確認ダイアログでその件数を警告します。使用中のテンプレートを削除すると、そのビューは**テンプレートが未設定**になります（現在の表示設定は保持されますが、テンプレートによる一括制御は外れます）。

## 「使用状況」の判定について

各ビューの **ビューテンプレート**（`ViewTemplateId`）を走査して、どのテンプレートがどのビューに適用されているかを集計しています。ビューテンプレートを持たないビュー（テンプレート未設定のビュー）は集計対象外です。

## 注意事項

- **削除は元に戻せません**（Undo は効きません）。使用状況をよく確認してから実行してください。
- ワークシェアリング環境でテンプレートの削除・名前変更を行う場合は、対象要素の所有権に注意してください。

## 関連機能

- **フィルタ整理** — 表示/グラフィックスの上書きで使うフィルタの使用ビュー確認・名前変更・削除。テンプレートと同じ操作感で整理できます。
