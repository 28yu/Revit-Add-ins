# 印刷しない注釈（タイプ名「非表示」）

画面には表示されるのに、**印刷・PDF・CAD 書き出しには出ない**テキスト・寸法・詳細線分を作れます。作業メモやチェック用のコメントに使えます。28 Tools を入れておくだけで自動で働きます（既定で ON）。

## 使い方

### 1. タイプの名前に「非表示」を入れる

テキストまたは寸法のタイプを複製し、タイプ名に **「非表示」** を入れます（例: `注釈_非表示`、`作業メモ（非表示）`）。そのタイプでテキスト・寸法を書きます（スポット寸法も対象）。

詳細線分は、**線種**の名前に「非表示」を入れます（管理 ＞ その他の設定 ＞ 線種 で作成）。

![タイプ名に「非表示」を入れる](./images/PrintHiddenText/01-type-name.png)

### 2. いつもどおり印刷・書き出しする

**印刷**、**書き出し ＞ PDF**、**書き出し ＞ CAD フォーマット**（DWG・DXF・DGN・ACIS）を実行するだけです。出力の間だけそのテキスト・寸法が隠れ、終わると元の表示に戻ります。

![画面には出るが PDF には出ない](./images/PrintHiddenText/02-result.png)

- シートを出力したときは、シートに配置したビュー（凡例を含む）の中のテキスト・寸法も隠れます
- タイプ名に「非表示」が無いテキスト・寸法には一切触りません。対象が無ければ通常どおり出力されます
- IFC・画像など、それ以外の書き出しには影響しません
- 印刷ダイアログの「プレビュー」では隠れません（Revit にプレビューを知らせる仕組みが無いため）。確認は PDF で行ってください

### ON / OFF の切り替え

**28 Tools ＞ 設定 ＞ 印刷非表示 ON** を押すと OFF になり、もう一度押すと ON に戻ります。OFF の間は「非表示」のものも印刷されます。設定はパソコンごとに保存されます。

![印刷非表示の ON/OFF ボタン](./images/PrintHiddenText/03-toggle.png)

## カーテンパネルの寸法数値も隠す

カーテンパネルファミリにネストした一般注釈（パネル幅の数値など）も、印刷・書き出しの間だけ消せます。

1. カーテンパネルファミリに、Yes/No の**タイプパラメータ「幅数値表示」**を作る
2. ネストした注釈の「表示」をそのパラメータに関連付ける

出力の間だけ、全カーテンパネルタイプの「幅数値表示」がオフになり、終わると元に戻ります。もともとオフのタイプや、パラメータが無いタイプには触りません。

> 出力後、「元に戻す」の履歴に「〜一時的に隠す（28 Tools）」「〜戻す（28 Tools）」が残ります。続けて「元に戻す」を押すと隠れた状態になるので、そのときは「やり直し」で戻してください。
