# 印刷しないテキスト（タイプ名「非表示」）

画面には表示されるのに、**印刷・PDF には出ない**テキストを作れます。作業メモやチェック用のコメントに使えます。ボタンはありません。28 Tools を入れておくだけで自動で働きます。

## 使い方

### 1. テキストタイプの名前に「非表示」を入れる

テキストのタイプを複製し、タイプ名に **「非表示」** を入れます（例: `注釈_非表示`、`作業メモ（非表示）`）。そのタイプでテキストを書きます。

![タイプ名に「非表示」を入れる](./images/PrintHiddenText/01-type-name.png)

### 2. いつもどおり印刷・PDF 出力する

**印刷** または **書き出し ＞ PDF** を実行するだけです。出力の間だけそのテキストが隠れ、終わると元の表示に戻ります。

![画面には出るが PDF には出ない](./images/PrintHiddenText/02-result.png)

- シートを出力したときは、シートに配置したビュー（凡例を含む）の中のテキストも隠れます
- タイプ名に「非表示」が無いテキストには一切触りません。対象が無ければ通常どおり出力されます
- DWG など PDF 以外の書き出しには影響しません

## カーテンパネルの寸法数値も隠す

カーテンパネルファミリにネストした一般注釈（パネル幅の数値など）も、印刷・PDF の間だけ消せます。

1. カーテンパネルファミリに、Yes/No の**タイプパラメータ「幅数値表示」**を作る
2. ネストした注釈の「表示」をそのパラメータに関連付ける

出力の間だけ、全カーテンパネルタイプの「幅数値表示」がオフになり、終わると元に戻ります。もともとオフのタイプや、パラメータが無いタイプには触りません。

> 出力後、「元に戻す」の履歴に「〜一時的に隠す（28 Tools）」「〜戻す（28 Tools）」が残ります。続けて「元に戻す」を押すと隠れた状態になるので、そのときは「やり直し」で戻してください。
