# DWGレイヤ表示設定の移行

Revit に読み込み／リンクした **DWG のレイヤごとの表示設定** を、開いている**別の Revit モデルへそのまま移行**する機能です。

表示/グラフィックスの上書き（V/G）ダイアログの **「読み込みカテゴリ」タブ** で設定した内容 —— レイヤの表示/非表示、線の色・線幅・線種、ハーフトーン —— が対象です。

同じ DWG を使う別モデルや、モデルを分割したときに、レイヤの表示設定を一つずつ手作業でやり直す必要がなくなります。

## Revit 標準機能との違い

| 設定の場所 | Revit 標準 | 本機能 |
|--|--|--|
| オブジェクトスタイル ＞ 読み込まれたオブジェクト（モデル全体） | 「プロジェクト標準の転送」で移せる | 対象外 |
| **表示/グラフィックスの上書き ＞ 読み込みカテゴリ（ビュー単位）** | **移せない** | **対象** |

ビュー単位の V/G はプロジェクト標準の転送では移せないため、本機能はそこを補います。

## 前提条件

- **移行元・移行先の両方のモデルを Revit で開いておく**こと。Excel などの中間ファイルは使いません。
- **移行先モデルにも同じ DWG が読み込み／リンクされている**こと。
  DWG のレイヤは Revit が DWG を読み込んだときに自動生成するもので、後から作ることはできません。DWG が入っていないモデルには設定だけを流し込めません。

## 画面構成

```
┌──────────────────────────────────────────┐
│ 移行元モデル / 移行先モデル / 反映先の単位                  │
├─────────────────────┬────────────────────┤
│ 移行元モデル データ情報      │ 移行先モデル データ情報      │
│  ① 読み取り元のビューを選択   │  ③ 反映するビューを選択（複数可）│
│  ② このビューにある DWG を選択 │  ④ 反映先の DWG を選択（複数可）│
└─────────────────────┴────────────────────┘
```

左で「どのビューの、どの DWG の設定を読み取るか」を決め、右で「どのビューの、どの DWG に反映するか」を決めます。

**移行元は常にビュー単位です。** 上部の「反映先の単位」は右側（移行先）にだけ効きます。

## 使い方

1. **移行先**のモデル（設定を反映したい側）をアクティブにします。
2. リボン **28 Tools ＞ シート・ビュー ＞ DWG表示移行** をクリックします。
3. ダイアログ上部で設定します。

   | 項目 | 内容 |
   |--|--|
   | 移行元モデル | 開いている他のモデルから、設定のコピー元を選びます |
   | 移行先モデル | アクティブなモデル（固定・表示のみ） |
   | 反映先の単位 | 右側の一覧を **ビュー** / **ビューテンプレート** のどちらで出すか（既定はビュー）。ビューを選んでおけば、テンプレート制御下のビューは自動でテンプレートへ振り替わります |

4. **① 左のビュー一覧**から読み取り元のビューを選びます。検索欄で絞り込めます。
5. **② その下の DWG 一覧**から読み取り元の DWG を選びます。
   - ここに並ぶのは、**選択したビューにある DWG だけ**です。モデルに読み込み／リンクした DWG（全ビューに現れるもの）に加え、そのビューにだけ貼り付けた DWG（**このビュー専用**と表示）が対象になります。
   - 各行の右に「◯レイヤ / 設定 △」と出ます。△ が、そのビューでそのDWGに実際に効いている設定の件数です。設定があるものが上に並び、自動で選択されます。
6. **③ 右のビュー一覧**で、反映先のビューにチェックを入れます。**複数選択できます。**
   - 左でビューを選ぶと、同名の移行先ビューが自動でチェックされます。
   - 「全選択」「選択解除」は、検索で**表示中の行だけ**を対象にします。
   - ビューテンプレートに V/G を制御されているビューは、状態列に「ビューテンプレート「◯◯」へ書き込みます」と出ます。そのまま選んで問題ありません（下記参照）。
7. **④ 反映先の DWG** にチェックを入れます。**複数選択できます。**
   - 同名の DWG が自動でチェックされます。同名が無ければ、レイヤ名の一致数が最も多いものが選ばれます。
   - 自動選択が意図と違う場合は、チェックを付け替えてください。同じレイヤ構成の DWG が複数ある場合は、まとめて選べます。
   - 各行の右の「◯レイヤ / 一致 △」で、読み取り元のレイヤがいくつ一致するか確認できます。
8. 画面下部のサマリで内容を確認し、**「設定を移行」** を押します。確認ダイアログで **はい** を選ぶと反映されます。

## DWG の表示設定は 2 段構え

Revit では DWG レイヤの見た目が 2 か所で決まります。**片方だけ移しても表示は揃いません。**

| | 場所 | 効く範囲 |
|--|--|--|
| **基準値** | 管理 ＞ オブジェクトスタイル ＞ 読み込みオブジェクト | モデル全体 |
| **上書き** | ビューの V/G ＞ 読み込みカテゴリ | そのビューだけ（基準値への**差分**） |

V/G は「上書きした項目」しか持ちません。上書きしていないレイヤの見た目は基準値で決まるため、モデル間で基準値が違えば V/G を完全に一致させても表示は揃いません。

本機能は既定で**両方**を移行します。基準値だけ移したくない場合は、上部の「オブジェクトスタイル（線の色・太さ・線種）も揃える」のチェックを外してください。

⚠️ オブジェクトスタイルは**モデル全体に効きます**。選んだビューだけの変更ではありません。

## 移行される項目

### ビューの V/G（選んだビューのみ）

| 項目 | 内容 |
|--|--|
| 表示 / 非表示 | レイヤごとの表示チェック |
| 投影線 / 切断線 | 色・線幅・線種 |
| サーフェス パターン | 前景・背景（パターン・色・表示） |
| 切断 パターン | 前景・背景（パターン・色・表示） |
| 透明度 | 0〜100 |
| ハーフトーン | オン / オフ |
| 詳細レベル | 粗い / 中間 / 詳細 |

`OverrideGraphicSettings` が持つ項目をすべて移します。**移す項目を絞り込むと、絞った項目に設定が入っていた場合に「移行したのに変わらない」状態になる**ため、間引きはしません。

### オブジェクトスタイル（モデル全体）

| 項目 | 内容 |
|--|--|
| 線の色 | レイヤごとの色 |
| 線の太さ | 投影・切断 |
| 線種 | 投影・切断 |

DWG 本体（親カテゴリ）の設定も同時に移行します。

### 「そっくりそのまま同じ状態にする」動作です

本機能は選んだレイヤの設定を**丸ごとミラーリング**します。移行元で何も設定していない（既定のままの）レイヤは、**移行先でも既定に戻ります**。

移行元と移行先で表示状態を完全に一致させるための仕様です。そのため、結果ダイアログに出る件数は「設定を書き込んだレイヤの数」であり、一覧の「設定数」列（＝既定から変えてあるレイヤの数）とは一致しません。

## なぜ移行元は「ビュー」だけなのか

ビューテンプレートの V/G は、**「読み込み」カテゴリの「含める」チェックが外れている**ことがあります。その場合、DWG の表示設定はテンプレートではなく**ビューのプロパティ側（V/G 設定）で個別に**持たれています。

テンプレートを読み取り元にすると、この個別設定を取りこぼします。一方、**ビューを読み取り元にすれば、テンプレート由来か個別設定かに関係なく「そのビューで実際に効いている値」が取れます。**

そのため移行元は常にビュー単位に固定しています。テンプレートで管理しているモデルでも、そのテンプレートを使っているビューを1つ選べば同じ結果になります。

## 「反映先の単位」の選び方

こちらは書き込み先の選択なので、運用に合わせて選びます。

- **ビュー**（既定）
  選んだビューに直接書き込みます。ビュー個別に V/G を設定している場合はこちら。
- **ビューテンプレート**
  テンプレート運用が徹底されているモデル向け。テンプレートを直せば、それを使う全ビューに一度で反映されます。

### テンプレート制御下のビューは自動でテンプレートへ書き込みます

Revit の仕様上、**ビューテンプレートが「読み込みカテゴリ」の V/G を制御しているビューは、ビュー側から直接変更できません**。

本機能はこれを事前に判定し、該当するビューを選んだ場合は**書き込み先をそのビューテンプレートへ自動で振り替えます**。単位を切り替え直す必要はありません。状態列に振り替え先のテンプレート名が表示されます。

- 同じテンプレートを使うビューを複数選んでも、**テンプレートへの書き込みは 1 回**にまとめられます。
- **そのテンプレートを使っている他のビューにも反映されます。** 実行前の確認ダイアログに、何件のビューがどれだけのテンプレートへ振り替えられるかを表示します。
- テンプレートに制御されていないビューは、これまでどおりビューへ直接書き込みます。
- 振り替えるかどうかは**事前の判定ではなく、実際にビューへ書き込んで効いたかどうか**で決めています。書けたつもりで何も変わらない、という状態が起きないようにするためです。そのため、事前の確認ダイアログに出なかったビューがテンプレートへ振り替わることもあります。実際の内訳は結果ダイアログに出ます。

逆に、反映先の単位を **ビューテンプレート** にした際に、**そのテンプレートが「読み込みカテゴリ」を制御していない**場合は警告を表示し、その行は選べません。設定を書き込んでもビューには反映されないため、先にテンプレート側で V/G の「読み込み」に含めるチェックを入れてください。

## 名前による照合について

ElementId はモデル間で意味を持たないため、照合はすべて**名前**で行っています。

| 対象 | 照合方法 |
|--|--|
| DWG | 一覧から**手動で選択**（同名を自動選択、無ければ一致レイヤ数が最多のもの） |
| ビュー / ビューテンプレート | 一覧から**手動で選択**（同名を自動チェック） |
| レイヤ | サブカテゴリ名の一致（自動） |
| 線種 | 線種名の一致（自動） |

DWG とビューは一覧から選ぶ形なので、名前が違っていても問題なく対応付けられます。レイヤと線種だけは名前の完全一致で自動照合します。

移行先で解決できなかったものは、実行後の結果ダイアログに一覧で表示されます。

- **見つからなかったレイヤ** — 移行先の DWG に同名のレイヤがない。そのレイヤの設定はスキップされます。
- **存在しない線種** — 移行先に同名の線種がない。線種だけが既定のまま（色・線幅は反映）になります。移行先に同名の線種を作ってから再実行すれば解決します。

## うまく反映されないときは

結果ダイアログに理由を出しています。まずそこを確認してください。

| 表示 | 意味と対処 |
|--|--|
| 移行元の「このビュー × この DWG」には、既定から変更された設定がありませんでした | 移行元が既定のままです。DWG 一覧の「設定 ◯」が 1 以上のものを選んでください |
| 移行先の DWG に見つからなかったレイヤ | レイヤ名が一致していません。移行先に同じ DWG を読み込み／リンクしてください |
| 反映できなかったビュー | ビューにもビューテンプレートにも書き込めなかったものです。件数と理由が出ます |

さらに詳しい経過は `C:\temp\Tools28_debug.txt` に記録しています。ビューごとに「反映 / 未反映 / 失敗」の件数とエラー内容が残るので、原因の切り分けに使ってください。

## 注意事項

- **移行先ビューの現在の設定は上書きされます。** 実行後に **Ctrl+Z** で元に戻せます。
- ラインワークツールで個別に変更した線の色などは、Revit API から取得・設定できないため移行できません（レイヤ単位の設定は移行できます）。
- 移行元・移行先のどちらもリンクモデルではなく、Revit で直接開いているモデルである必要があります。
- 移行元モデルは読み取りのみで、変更されません。
