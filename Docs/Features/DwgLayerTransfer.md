# DWGレイヤ表示設定の移行

Revit に読み込み／リンクした **DWG のレイヤごとの表示設定** を、開いている**別の Revit モデルへそのまま移行**する機能です。

表示/グラフィックスの上書き（V/G）ダイアログの **「読み込みカテゴリ」タブ** で設定した内容 —— レイヤの表示/非表示、線の色・線幅・線種、ハーフトーン —— が対象です。

同じ DWG を使う別モデルや、モデルを分割したときに、レイヤの表示設定を一つずつ手作業でやり直す必要がなくなります。

## Revit 標準機能との違い

| 設定の場所 | Revit 標準 | 本機能 |
|--|--|--|
| オブジェクトスタイル ＞ 読み込まれたオブジェクト（モデル全体） | 「プロジェクト標準の転送」で移せる | 対象外 |
| **表示/グラフィックスの上書き ＞ 読み込みカテゴリ（ビュー単位）** | **移せない** | **対象** |

ビュー単位の V/G はプロジェクト標準の転送では移せないため、本機能はそこを補います。

## 前提条件

- **移行元・移行先の両方のモデルを Revit で開いておく**こと。Excel などの中間ファイルは使いません。
- **移行先モデルにも同じ DWG が読み込み／リンクされている**こと。
  DWG のレイヤは Revit が DWG を読み込んだときに自動生成するもので、後から作ることはできません。DWG が入っていないモデルには設定だけを流し込めません。

## 画面構成

```
┌──────────────────────────────────────────┐
│ 移行元モデル / 移行先モデル / 移行の単位                    │
├─────────────────────┬────────────────────┤
│ 移行元モデル データ情報      │ 移行先モデル データ情報      │
│  ① ビューを選択           │  ③ 反映するビューを選択（複数可）│
│  ② このビューにある DWG を選択 │  ④ 反映先の DWG を選択      │
└─────────────────────┴────────────────────┘
```

左で「どのビューの、どの DWG の設定を参照するか」を決め、右で「どのビューの、どの DWG に反映するか」を決めます。

## 使い方

1. **移行先**のモデル（設定を反映したい側）をアクティブにします。
2. リボン **28 Tools ＞ シート・ビュー ＞ DWG表示移行** をクリックします。
3. ダイアログ上部で設定します。

   | 項目 | 内容 |
   |--|--|
   | 移行元モデル | 開いている他のモデルから、設定のコピー元を選びます |
   | 移行先モデル | アクティブなモデル（固定・表示のみ） |
   | 移行の単位 | **ビューテンプレート** / **ビュー** のいずれか |

4. **① 左のビュー一覧**から参照元のビューを選びます。検索欄で絞り込めます。
5. **② その下の DWG 一覧**から参照元の DWG を選びます。
   - ここに並ぶのは、**選択したビューにある DWG だけ**です。モデルに読み込み／リンクした DWG（全ビューに現れるもの）に加え、そのビューにだけ貼り付けた DWG（**このビュー専用**と表示）が対象になります。
   - 各行の右に「◯レイヤ / 設定 △」と出ます。△ が、そのビューでそのDWGに実際に設定されている件数です。設定があるものが上に並び、自動で選択されます。
6. **③ 右のビュー一覧**で、反映先のビューにチェックを入れます。**複数選択できます。**
   - 左でビューを選ぶと、同名の移行先ビューが自動でチェックされます。
   - 「全選択」「選択解除」は、検索で**表示中の行だけ**を対象にします。
7. **④ 反映先の DWG** を選びます。
   - 同名の DWG が自動で選択されます。同名が無ければ、レイヤ名の一致数が最も多いものが選ばれます。
   - 各行の右の「◯レイヤ / 一致 △」で、参照元のレイヤがいくつ一致するか確認できます。
8. 画面下部のサマリで内容を確認し、**「設定を移行」** を押します。確認ダイアログで **はい** を選ぶと反映されます。

## 移行される項目

| 項目 | 内容 |
|--|--|
| 表示 / 非表示 | レイヤごとの表示チェック |
| 投影線 | 色・線幅・線種 |
| 切断線 | 色・線幅・線種 |
| ハーフトーン | オン / オフ |

DWG 本体（親カテゴリ）の設定も同時に移行します。

サーフェスパターンや透明度は DWG のジオメトリには効かないため対象外にしています。移行先の設定を無用にリセットしないための判断です。

### 「そっくりそのまま同じ状態にする」動作です

本機能は選んだレイヤの設定を**丸ごとミラーリング**します。移行元で何も設定していない（既定のままの）レイヤは、**移行先でも既定に戻ります**。

移行元と移行先で表示状態を完全に一致させるための仕様です。そのため、結果ダイアログに出る件数は「設定を書き込んだレイヤの数」であり、一覧の「設定数」列（＝既定から変えてあるレイヤの数）とは一致しません。

## 「移行の単位」の選び方

- **ビューテンプレート**（推奨）
  テンプレート運用が徹底されているモデルなら、こちらの方が対象数が少なく確実です。テンプレートを直せば、それを使う全ビューに一度で反映されます。
- **ビュー**
  ビュー個別に V/G を設定している場合はこちら。ただし下記の制約があります。

### ビューテンプレートに関する制約

Revit の仕様上、**ビューテンプレートが「読み込みカテゴリ」の V/G を制御しているビューは、ビュー側から直接変更できません**。

本機能はこれを事前に判定し、該当するビューを状態列に赤字で表示してチェックできないようにしています。この場合は「移行の単位」を **ビューテンプレート** に切り替えて、テンプレート側へ移行してください。

逆に、テンプレート単位で移行する際に、**そのテンプレートが「読み込みカテゴリ」を制御していない**場合も警告を表示します。設定を書き込んでもビューには反映されないため、先にテンプレート側で V/G を有効にしてください。

## 名前による照合について

ElementId はモデル間で意味を持たないため、照合はすべて**名前**で行っています。

| 対象 | 照合方法 |
|--|--|
| DWG | 一覧から**手動で選択**（同名を自動選択、無ければ一致レイヤ数が最多のもの） |
| ビュー / ビューテンプレート | 一覧から**手動で選択**（同名を自動チェック） |
| レイヤ | サブカテゴリ名の一致（自動） |
| 線種 | 線種名の一致（自動） |

DWG とビューは一覧から選ぶ形なので、名前が違っていても問題なく対応付けられます。レイヤと線種だけは名前の完全一致で自動照合します。

移行先で解決できなかったものは、実行後の結果ダイアログに一覧で表示されます。

- **見つからなかったレイヤ** — 移行先の DWG に同名のレイヤがない。そのレイヤの設定はスキップされます。
- **存在しない線種** — 移行先に同名の線種がない。線種だけが既定のまま（色・線幅は反映）になります。移行先に同名の線種を作ってから再実行すれば解決します。

## 注意事項

- **移行先ビューの現在の設定は上書きされます。** 実行後に **Ctrl+Z** で元に戻せます。
- ラインワークツールで個別に変更した線の色などは、Revit API から取得・設定できないため移行できません（レイヤ単位の設定は移行できます）。
- 移行元・移行先のどちらもリンクモデルではなく、Revit で直接開いているモデルである必要があります。
- 移行元モデルは読み取りのみで、変更されません。

- **テンプレート整理** — ビューテンプレートの使用状況確認・整理。
