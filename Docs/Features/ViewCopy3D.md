# 3Dビュー 視点合わせ

3Dビューのカメラ位置と向きを、別の3Dビューにそのまま写します。

![Before / After：視点がそろった2つの3Dビュー](./images/ViewCopy3D/00-result.png)

---

## 使い方

操作は Revit の「タイプ プロパティを一致」（MA）と同じ感覚です。

### 1. コピー元で押す

コピー元の3Dビューを開き、「**28 Tools**」タブ →「**3Dビュー**」パネル →「**視点合わせ**」をクリック。視点を覚え、**カーソルの横に印**が出ます。

![「視点合わせ」をクリックすると、カーソルの横に印が出る](./images/ViewCopy3D/01-copy.png)

### 2. 合わせたいビューで押す

印が出ている間に、合わせたい3Dビューを開いて「**視点合わせ**」をクリックすると、すぐに貼られます。続けてほかのビューにも貼れます。

![合わせたいビューで「視点合わせ」をクリック](./images/ViewCopy3D/02-paste.png)

| こんなとき | 操作 |
|---|---|
| 何枚もの3Dビューにまとめて貼る | プロジェクトブラウザで3Dビューを複数選んでからボタンを押す |
| 視点と切断ボックスを一度に貼る | 「視点合わせ」と「切断ボックス合わせ」を両方押して印を2つ出してから、合わせたいビューでどちらかを押す |
| コピーを取りやめる | **Esc**（印が消えます） |

---

## 注意

- 3Dビュー同士でのみ使えます（パース・アイソメどちらも可）
- コピー内容は Revit を閉じると消えます
- 切断ボックスの範囲は写りません → [切断ボックス合わせ](./SectionBoxCopy.md)
