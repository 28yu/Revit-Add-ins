# 3Dビュー視点 コピー＆ペースト

3Dビューのカメラ位置と向きを、別の3Dビューにそのまま写します。

![Before / After：視点がそろった2つの3Dビュー](./images/ViewCopy3D/00-result.png)

---

## 使い方

### 1. 視点をコピー

コピー元の3Dビューを開き、「**28 Tools**」タブ →「**3Dビュー**」パネル →「**視点コピー**」をクリック。

![「視点コピー」をクリック](./images/ViewCopy3D/01-copy.png)

### 2. 視点をペースト

貼り付け先の3Dビューを開き、「**視点ペースト**」をクリック。

![「視点ペースト」をクリック](./images/ViewCopy3D/02-paste.png)

> 💡 プロジェクトブラウザで3Dビューを**複数選択**してからペーストすると、まとめて適用できます。

---

## 注意

- 3Dビュー同士でのみ使えます（パース・アイソメどちらも可）
- コピー内容は Revit を閉じると消えます
- 切断ボックスの範囲は写りません → [切断ボックス コピー＆ペースト](./SectionBoxCopy.md)
