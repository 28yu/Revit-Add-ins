# 3Dビュー 視点合わせ

3Dビューのカメラ位置と向きを、別の3Dビューにそのまま写します。

![Before / After：視点がそろった2つの3Dビュー](./images/ViewCopy3D/00-result.png)

---

## 使い方

### 1. コピー元で押す

コピー元の3Dビューを開き、「**28 Tools**」タブ →「**3Dビュー**」パネル →「**視点合わせ**」をクリック。視点を覚えます。

![「視点合わせ」をクリック](./images/ViewCopy3D/01-copy.png)

### 2. 合わせたいビューで押す

合わせたい3Dビューを開いて、もう一度「**視点合わせ**」をクリックし、「**このビューに貼る**」を選びます。

![「このビューに貼る」を選ぶ](./images/ViewCopy3D/02-paste.png)

| こんなとき | 操作 |
|---|---|
| コピー元を変える | 手順 2 で「**このビューをコピー元にする**」を選ぶ |
| 何枚もの3Dビューにまとめて貼る | プロジェクトブラウザで3Dビューを複数選んでからボタンを押す |

---

## 注意

- 3Dビュー同士でのみ使えます（パース・アイソメどちらも可）
- コピー内容は Revit を閉じると消えます
- 切断ボックスの範囲は写りません → [切断ボックス合わせ](./SectionBoxCopy.md)
