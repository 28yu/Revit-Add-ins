# パラメータ値の一括置換 使い方ガイド

モデル内の**文字パラメータの値**を探して、別の値にまとめて置き換える機能です。置換後の値を空欄にすると、**値を削除**できます。

Excel への書き出し・読み込みを使わずに Revit 上で直接変更するので、大容量モデルでも短時間で処理できます。

---

## できること

- モデル全体（またはアクティブビュー・選択要素）から、指定した値を持つ文字パラメータを探します
- 見つかったものを**カテゴリ × パラメータごと**に一覧表示し、件数を確認できます
- チェックを付けたものだけを置き換えます（置換後の値を空欄にすると削除）
- インスタンスパラメータ・タイプパラメータの両方に対応します

**例**: すべての要素の「未使用」という値を消したい → 検索する値「未使用」、置換後の値「（空欄）」で実行

---

## 実行手順

### ▶ ステップ1: コマンドの起動

リボン「**28 Tools**」タブ →「**パラメータ**」パネル →「**値の一括置換**」をクリックします。

（要素を選択してから起動すると、範囲が「選択要素」になります）

### ▶ ステップ2: 条件を入力して検索

| 項目 | 内容 |
|---|---|
| **検索する値** | 探す値（例:「未使用」） |
| **置換後の値** | 置き換える値。**空欄なら値を削除** |
| **値全体が一致** | パラメータの値全体が検索する値と同じものだけ（前後の空白は無視）。通常はこちら |
| **値の一部に含む** | 検索する値を含むものを対象に、その部分だけを置き換え（例:「B1F」→「B1FL」） |
| **タイプパラメータも対象** | オンにするとタイプパラメータも探します |
| **範囲** | プロジェクト全体 / アクティブビュー / 選択要素 |

「**検索**」をクリックすると、見つかったものがカテゴリ・パラメータごとに一覧表示されます。検索中は進み具合が表示され、「**中止**」で止められます。

### ▶ ステップ3: 置き換えるものを選んで実行

- 一覧の「**置換**」列のチェックで、置き換えるものを選びます（初期状態はすべてチェックあり）
- 同じ名前のパラメータが複数ある場合は「種別」（共有／組み込み／プロジェクト）で区別できます
- 「**置換を実行**」→ 確認画面で件数を確認して「はい」

置換中も進み具合が表示され、「中止」で止めると**それまでの変更はすべて元に戻ります**。完了すると、成功・失敗・対象外の件数が表示されます。

> 💡 実行後に Revit の「元に戻す」（Ctrl+Z）で、置換全体を1回で取り消せます。

---

## 対象にならないもの

- 数値（長さ・面積など）・要素参照（レベル・材料など）のパラメータ
- 読み取り専用のパラメータ（計算値など）
- 値が入っていないパラメータ

---

## トラブルシューティング

### 検索に時間がかかる

大容量モデルでは、全要素のパラメータを調べるため時間がかかります。進み具合が表示されている間は処理中です。範囲を「アクティブビュー」「選択要素」に絞ると速くなります。

### 「対象外」の件数が出た

検索してから実行するまでの間に値が変わったものです（他の操作で変更された等）。必要なら検索し直してください。

### 処理の記録

`C:\temp\Tools28_debug.txt` に `[ValueReplace]` として検索条件・件数・処理時間が記録されます。不具合報告の際に添えてください。
