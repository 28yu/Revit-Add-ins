# マニュアル用スクリーンショット

`Docs/Features/<機能ID>.md` に貼る画像の置き場です。
28tools.com のマニュアルページを作るとき（`28tools-download` の `scripts/build-manuals/inject.mjs`）に、
画像はサイト側の `images/manual/` へ自動でコピーされます。

## 書き方（MD 側）

```markdown
![「視点コピー」をクリック](./images/ViewCopy3D/01-copy.png)
```

- `[ ]` の中の文字が、画像の下に出る説明文になります（短く、何をする画面かだけ書く）
- **画像がまだ無い枠は、サイトでは自動で非表示**になります。先に枠だけ書いておいて大丈夫です

## 書き方の手本

Revit Peeler（revitpeeler.com）の書き方を参考にしています。

- **1手順＝1〜2文＋スクショ1枚**。文章で長く説明せず、画面を見せる
- 画像の下の説明文は「何をする画面か」を短く（例：「セルを選択して CTRL+C」）
- 1ページの文章は 300〜500字程度を目安にし、増やさない

## 撮り方の決まり

| 項目 | 決まり |
|---|---|
| 置き場所 | `images/<機能ID>/` |
| ファイル名 | `00-result.png`（できあがりの例）、`01-…png`、`02-…png`（手順の順番） |
| 形式 | PNG。横幅 1200〜1600px 程度。Revit の UI は日本語 |
| クリックする場所 | **赤い四角**で囲む（Windows の「Snipping Tool」のペンで可） |
| 写さないもの | 実案件の図面・プロジェクト名・社名・個人名（サンプルモデルを使う） |

- `00-result.png` は「使う前／使った後」が1枚で分かる画像にする（左右に並べる、など）
- 手順の画像は「リボンのボタン」「開くダイアログ」など、**操作する場所が分かる範囲**で切り抜く（画面全体はいらない）
